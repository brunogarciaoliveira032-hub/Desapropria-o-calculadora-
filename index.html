🤖 Fallback por IA para campos não encontrados (opcional)

Quando a leitura por padrões não encontra um campo (ou encontra com baixa confiança), você pode pedir para a IA da Anthropic tentar completá-lo — só quando você clicar no botão que aparece na conferência, nunca automaticamente. Isso envia o trecho relevante do PDF (não o processo inteiro) para a API da Anthropic usando sua própria chave. A chave fica salva só neste navegador (localStorage), nunca é enviada a mais ninguém além da própria Anthropic.

🔎 Consulta automática de advogado pela OAB (opcional)

Com um token cadastrado, o campo "Advogado(a)" é preenchido automaticamente ao sair do campo OAB (ex.: "OAB/SP 123.456"). Sem token salvo, o preenchimento continua manual. O token fica salvo só neste navegador (localStorage) e é enviado apenas ao provedor de consulta configurado — hoje, a API da Exato Digital (api.exato.digital); ela é paga e cobra por consulta, então confirme o plano deles antes de usar em produção. Se você usa outro provedor, me avise para eu trocar o endpoint em js/consultaOab.js.
